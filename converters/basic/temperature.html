Common Temperature Conversions

      
    
        
  • 0°C (freezing) = 32°F = 273.15 K = 491.67°R
    • 
        
  • 100°C (boiling) = 212°F = 373.15 K = 671.67°R
    • 
        
  • 37°C (body temperature) = 98.6°F = 310.15 K
    • 
        
  • -40°C = -40°F (the only point where Celsius and Fahrenheit are equal)
    • 
        
  • 0 K (absolute zero) = -273.15°C = -459.67°F = 0°R
    • 
        
  • 0°C = 0°Ré; 100°C = 80°Ré (Réaumur scale: ×0.8)
    • 
        
  • 0°C = 150°De; 100°C = 0°De (Delisle scale - inverted)
    • 
        
  • 0°C = 0°N; 100°C = 33°N (Newton scale)
    • 
        
  • 0°C = 7.5°Rø; 100°C = 60°Rø (Rømer scale)
