About Pebibits per second

Pebibit per second (Pibit/s) = 2⁵⁰ bit/s ≈ 1.126 × 10¹⁵ bit/s (IEC 80000-13). NTT's 2024 lab record (1.53 Pbit/s ≈ 1.36 Pibit/s) is the only physical system that has approached this range. A full Frontier exascale node cluster would have aggregate memory bandwidth of ≈ 0.09 Pibit/s. Purely research-scale. 1 Pibit/s = 2⁵⁰ bit/s ≈ 125.9 TB/s.

About Petabits per second

Petabit per second (Pbit/s) = 10¹⁵ bit/s (SI). Research-scale only: NTT (2024) achieved 1.53 Pbit/s over a single fibre using space + wavelength division multiplexing. The combined peak of the world's largest internet exchange points (DE-CIX, AMS-IX) is multi-Tbit/s. Global IP traffic ≈ 1.8 Pbit/s sustained average in 2030 forecast. 1 Pbit/s = 10¹⁵ bit/s = 125 TB/s.
