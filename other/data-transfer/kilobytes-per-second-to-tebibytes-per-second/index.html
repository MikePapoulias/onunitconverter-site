About Kilobytes per second

Kilobyte per second (KB/s) = 1,000 B/s = 8,000 bit/s (SI). Legacy modem throughput: 56 kbit/s dial-up ≈ 7 KB/s; ISDN 128 kbit/s = 16 KB/s. RS-232 at 115,200 baud (8N1) = 11.52 KB/s. CD-ROM 1× = 150 KB/s; 52× = 7,800 KB/s. Bluetooth 2.1 EDR ≈ 300 KB/s; USB 1.1 Full Speed = 1,500 KB/s. 1 KB/s = 1,000 B/s = 8 kbit/s.

About Tebibytes per second

Tebibyte per second (TiB/s) = 2⁴⁰ B/s (IEC 80000-13). HPC memory scale: AMD MI300A APU = 5.3 TB/s ≈ 4.82 TiB/s; Frontier compute blade (4 GPUs + 1 CPU) ≈ 20 TiB/s aggregate HBM bandwidth. DGX H100 (8 GPUs via NVSwitch) ≈ 6.55 TiB/s GPU-GPU bandwidth. CXL 3.0 rack-scale pooled memory fabric targets low TiB/s. 1 TiB/s = 2⁴⁰ B/s = 8 Tibit/s.
