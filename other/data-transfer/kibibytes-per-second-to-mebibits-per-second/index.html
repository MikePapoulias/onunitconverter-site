Conversion Formula

Mibit/s = KiB/s × 0.0078125

About Kibibytes per second

Kibibyte per second (KiB/s) = 2¹⁰ = 1,024 B/s = 8,192 bit/s (IEC 80000-13). Used in embedded I/O specs and real-time OS throughput documentation. SD card speed classes: Class 10 = 10,000 KB/s ≈ 9,766 KiB/s; UHS-3 = 30,000 KB/s ≈ 29,297 KiB/s. STM32F4 FLASH page write ≈ 16 KiB/s; Arduino Uno SPI at 4 MHz = 500 KiB/s. 1 KiB/s = 1,024 B/s = 8,192 bit/s.

About Mebibits per second

Mebibit per second (Mibit/s) = 2²⁰ = 1,048,576 bit/s (IEC 80000-13). Used in FPGA-to-memory interface specs and JEDEC memory bus timing documents where bit rates are derived from 2ⁿ clock frequencies. A 100 MHz 8-bit parallel bus = 800 Mibit/s. Contrasted with Mbit/s (= 10⁶ bit/s). 1 Mibit/s = 1,048,576 bit/s ≈ 131 KB/s.
