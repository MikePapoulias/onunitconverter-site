About Petabytes per second

Petabyte per second (PB/s) = 10¹⁵ B/s (SI). Theoretical for single systems. NTT 2024 fibre lab record = 191 TB/s ≈ 0.19 PB/s. Exascale HPC with 10,000 nodes × 10 TB/s memory bandwidth each = 100,000 TB/s = 100 PB/s in aggregate - plausible as a cluster total but not a single link. Global all-data-centre combined write throughput ≈ 1-10 PB/s. 1 PB/s = 10¹⁵ B/s = 8 Pbit/s.

About Exabits per second

Exabit per second (Ebit/s) = 10¹⁸ bit/s (SI). Theoretical: Shannon limit for a single-mode fibre over 50 THz optical bandwidth ≈ 100 Pbit/s - still ~10,000× below 1 Ebit/s. Reaching 1 Ebit/s would require ≈1 million parallel fibres each at 1 Pbit/s. Global internet backbone installed capacity in 2024 ≈ 5-10 Pbit/s. 1 Ebit/s = 10¹⁸ bit/s = 125 PB/s.
