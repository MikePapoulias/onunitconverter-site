Conversion Formula

GiB/s = MiB/s × 0.0009765625

About Mebibytes per second

Mebibyte per second (MiB/s) = 2²⁰ = 1,048,576 B/s (IEC 80000-13). Used in Linux fio/dd benchmark output. Optical disc speeds: CD-ROM 1× = 150 KiB/s; 52× ≈ 7.62 MiB/s; Blu-ray 1× ≈ 4.39 MiB/s; 12× Blu-ray ≈ 52.73 MiB/s. SATA II effective throughput ≈ 286 MiB/s. microSD A1 spec = 10 MB/s ≈ 9.54 MiB/s. 1 MiB/s = 1,048,576 B/s = 8 Mibit/s.

About Gibibytes per second

Gibibyte per second (GiB/s) = 2³⁰ B/s (IEC 80000-13). Precision unit for STREAM benchmark and LIKWID memory bandwidth measurements. Intel Xeon Platinum 8380 dual-socket STREAM ≈ 400 GiB/s. RTX 4090 GDDR6X = 1,008 GB/s ≈ 939 GiB/s. PCIe 5.0 ×16 = 64 GB/s ≈ 59.6 GiB/s. AMD EPYC Infinity Fabric (4-socket) ≈ 576 GiB/s cross-die. 1 GiB/s = 2³⁰ B/s = 8 Gibit/s.
