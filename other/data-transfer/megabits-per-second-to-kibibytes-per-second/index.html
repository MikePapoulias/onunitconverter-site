Conversion Formula

About Megabits per second

Megabit per second (Mbit/s) = 10⁶ bit/s (SI). Standard consumer broadband unit: ADSL2+ up to 24 Mbit/s; VDSL2 up to 100 Mbit/s; Wi-Fi 6 up to 9,608 Mbit/s; Gigabit Ethernet = 1,000 Mbit/s. Streaming: Netflix 1080p = 5 Mbit/s; 4K HDR = 15-25 Mbit/s; 4K Blu-ray up to 128 Mbit/s. ISP 100 Mbit/s ≈ 12.5 MB/s download. 1 Mbit/s = 10⁶ bit/s = 125 KB/s.

About Kibibytes per second

Kibibyte per second (KiB/s) = 2¹⁰ = 1,024 B/s = 8,192 bit/s (IEC 80000-13). Used in embedded I/O specs and real-time OS throughput documentation. SD card speed classes: Class 10 = 10,000 KB/s ≈ 9,766 KiB/s; UHS-3 = 30,000 KB/s ≈ 29,297 KiB/s. STM32F4 FLASH page write ≈ 16 KiB/s; Arduino Uno SPI at 4 MHz = 500 KiB/s. 1 KiB/s = 1,024 B/s = 8,192 bit/s.
