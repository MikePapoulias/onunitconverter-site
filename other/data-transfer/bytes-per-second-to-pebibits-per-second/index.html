About Bytes per second

Byte per second (B/s) = 8 bit/s. The natural unit for file transfer speeds, disk I/O, and memory bandwidth reported by OS tools and storage benchmarks. ISP 'Mbit/s' ÷ 8 = MB/s download speed: a 100 Mbit/s connection delivers ≈ 12.5 MB/s. USB 2.0 = 60 MB/s; SATA III = 600 MB/s; Thunderbolt 4 = 5,000 MB/s. 1 B/s = 8 bit/s.

About Pebibits per second

Pebibit per second (Pibit/s) = 2⁵⁰ bit/s ≈ 1.126 × 10¹⁵ bit/s (IEC 80000-13). NTT's 2024 lab record (1.53 Pbit/s ≈ 1.36 Pibit/s) is the only physical system that has approached this range. A full Frontier exascale node cluster would have aggregate memory bandwidth of ≈ 0.09 Pibit/s. Purely research-scale. 1 Pibit/s = 2⁵⁰ bit/s ≈ 125.9 TB/s.
