About Exbibytes per second

Exbibyte per second (EiB/s) = 2⁶⁰ B/s ≈ 1.153 × 10¹⁸ B/s (IEC 80000-13). Total global data-centre write throughput in 2024 ≈ 1 EB/s ≈ 0.87 EiB/s in aggregate across all systems - but no single link approaches this. Shannon limit for a single-mode fibre full C-band ≈ 15 Tbit/s; reaching 1 EiB/s requires ≈ 500,000 such fibres. 1 EiB/s = 2⁶⁰ B/s ≈ 8 Eibit/s.

About Bytes per second

Byte per second (B/s) = 8 bit/s. The natural unit for file transfer speeds, disk I/O, and memory bandwidth reported by OS tools and storage benchmarks. ISP 'Mbit/s' ÷ 8 = MB/s download speed: a 100 Mbit/s connection delivers ≈ 12.5 MB/s. USB 2.0 = 60 MB/s; SATA III = 600 MB/s; Thunderbolt 4 = 5,000 MB/s. 1 B/s = 8 bit/s.
