About Bytes

The byte (B) is the fundamental addressable memory unit - 8 bits, 256 values (0-255). Standardised by the IBM System/360 (1964). UTF-8 encodes ASCII in 1 byte; Unicode in 1-4 bytes. One byte = 1 ASCII character, 1 RGB channel value, 1 PCM audio sample (8-bit). All mainstream CPU architectures (x86-64, ARM64, RISC-V) increment addresses by 1 byte. 1 byte = 8 bits = 2 nibbles.

About Kilobits

A kilobit (kbit) = 1,000 bits (SI). Standard unit for connection speeds: dial-up 9.6-56 kbit/s; ISDN 64-128 kbit/s; early ADSL 256 kbit/s. VoIP codecs: G.711 = 64 kbit/s; Opus (WhatsApp, Discord) = 6-510 kbit/s adaptive. Bluetooth LE up to 1,000 kbit/s; Zigbee/Z-Wave 20-250 kbit/s. 'kbit/s' = strictly decimal 1,000 bits/s (ITU/IEEE). 1 kbit = 1,000 bits = 125 bytes.
