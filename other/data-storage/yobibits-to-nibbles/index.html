About Yobibits

A yobibit (Yibit) = 2⁸⁰ bits ≈ 1.21 × 10²⁴ bits (IEC 80000-13, 2008). An 80-bit physical address space would provide 2⁸⁰ bytes = 128 YiB of byte-addressable memory - physically preposterous by any current forecast. World manufactured storage in 2023 ≈ 10 ZB ≈ 0.00828 Yibit. A 267-qubit quantum register has a state space of 2²⁶⁷ ≈ 1 Yibit in bits. IEC 2022 added 'ronbi' (Ri, 2⁹⁰) and 'quetti' (Qi, 2¹⁰⁰) for theoretical future use. 1 Yibit = 2⁸⁰ bits = 128 ZiB.

About Nibbles

A nibble is exactly 4 bits = half a byte, representing 2⁴ = 16 values - one hexadecimal digit (0-F). Used in BCD encoding (each decimal digit = 1 nibble; 2 nibbles per byte packs two BCD digits), financial/mainframe packed-decimal formats, and CSS hex colours (#RRGGBB = 2 nibbles per channel). 4-bit processors (Intel 4004, TI TMS1000) processed one nibble per cycle. 1 nibble = 4 bits = 0.5 bytes.
