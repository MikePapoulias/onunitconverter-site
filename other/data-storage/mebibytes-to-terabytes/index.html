About Mebibytes

A mebibyte (MiB) = 2²⁰ = 1,048,576 bytes (IEC 80000-13). Windows/older macOS report sizes in MiB but label them 'MB'. Linux malloc and kernel pages are power-of-2 aligned. Docker images: Alpine base 5 MiB; Ubuntu 72 MiB. Linux kernel bzImage 8-12 MiB. NVIDIA RTX 4090: 24 GiB GDDR6X in 2-GiB binary chunks. 1 MiB = 1,048,576 bytes = 1,024 KiB.

About Terabytes

A terabyte (TB) = 10¹² bytes (SI). Consumer HDDs: 1-22 TB; consumer NVMe SSDs: 1-8 TB. LTO-9 tape: 18 TB/cartridge; enterprise libraries: hundreds of petabytes. Whole genome sequencing: Illumina NovaSeq 6000 run ≈ 6 TB raw FASTQ. JWST downlinks ≈ 57 GB/day (≈20 TB/year). 4K NVR (64 cameras) ≈ 1 TB/day. 1 TB = 10¹² bytes = 1,000 GB.
