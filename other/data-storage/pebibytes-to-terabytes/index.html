About Pebibytes

A pebibyte (PiB) = 2⁵⁰ bytes = 1,125,899,906,842,624 bytes (IEC 80000-13). The Frontier exascale supercomputer (ORNL, 2022) has ≈700 PiB of Lustre file system storage across 5,408 HPE EX nodes. IBM Spectrum Scale HPC deployments manage 10-100 PiB namespaces. NASA's active Earth observation archive ≈ 100 PiB. All hyperscale cloud storage combined ≈ 300,000 PiB = 300 EiB as of 2024. 1 PiB = 2⁵⁰ bytes = 1,024 TiB.

About Terabytes

A terabyte (TB) = 10¹² bytes (SI). Consumer HDDs: 1-22 TB; consumer NVMe SSDs: 1-8 TB. LTO-9 tape: 18 TB/cartridge; enterprise libraries: hundreds of petabytes. Whole genome sequencing: Illumina NovaSeq 6000 run ≈ 6 TB raw FASTQ. JWST downlinks ≈ 57 GB/day (≈20 TB/year). 4K NVR (64 cameras) ≈ 1 TB/day. 1 TB = 10¹² bytes = 1,000 GB.
