About Kilobytes

A kilobyte (KB) = 1,000 bytes (SI). Used by all storage manufacturers (HDD, SSD, USB, SD) and endorsed by the IEC and FTC. Typical sizes: plain-text email 2-5 KB; HTML page 10-100 KB; Word document 10-30 KB. Ethernet MTU = 1,500 bytes ≈ 1.5 KB; jumbo frames 9 KB. MP3 at 128 kbit/s = 16 KB/s of audio. 1 KB = 1,000 bytes = 8,000 bits.

About Mebibytes

A mebibyte (MiB) = 2²⁰ = 1,048,576 bytes (IEC 80000-13). Windows/older macOS report sizes in MiB but label them 'MB'. Linux malloc and kernel pages are power-of-2 aligned. Docker images: Alpine base 5 MiB; Ubuntu 72 MiB. Linux kernel bzImage 8-12 MiB. NVIDIA RTX 4090: 24 GiB GDDR6X in 2-GiB binary chunks. 1 MiB = 1,048,576 bytes = 1,024 KiB.
