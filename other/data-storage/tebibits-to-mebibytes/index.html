About Tebibits

A tebibit (Tibit) = 2⁴⁰ = 1,099,511,627,776 bits (IEC 80000-13). JEDEC NAND roadmap targets: TLC at 300+ layers (2025-2026) aims for 1-2 Tibit per die. Samsung V-NAND 8th gen (2024) targets 1 Tibit/die; 2 TiB per stacked package. HBM3e stacked memory full roadmap projects 4 Tibit HBM stacks post-2030. 1 Tibit = 2⁴⁰ bits = 128 GiB.

About Mebibytes

A mebibyte (MiB) = 2²⁰ = 1,048,576 bytes (IEC 80000-13). Windows/older macOS report sizes in MiB but label them 'MB'. Linux malloc and kernel pages are power-of-2 aligned. Docker images: Alpine base 5 MiB; Ubuntu 72 MiB. Linux kernel bzImage 8-12 MiB. NVIDIA RTX 4090: 24 GiB GDDR6X in 2-GiB binary chunks. 1 MiB = 1,048,576 bytes = 1,024 KiB.
